# Teste rápido 4.18

1. Publique todos os arquivos da 4.18 no GitHub Pages.
2. Abra o Player com o código da tela e confirme a reprodução.
3. No iPhone, use Compartilhar > Adicionar à Tela de Início e abra pelo novo ícone. O Player deve abrir como web app, sem a interface normal do navegador.
4. Desligue a internet por alguns minutos. O conteúdo já armazenado deve continuar.
5. Ligue a internet novamente. A sincronização deve voltar automaticamente.
6. Deixe o Player rodando continuamente. O watchdog atua apenas se detectar reprodução travada por mais de 2 minutos.
