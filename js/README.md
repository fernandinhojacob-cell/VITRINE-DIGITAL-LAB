# Configuração

Copie:

`config.example.js` → `config.js`

Depois informe:
- URL do projeto Supabase
- publishable key

O `config.js` está no `.gitignore` para evitar que sua configuração local seja versionada.

O player aceita orientação por tela: `portrait` (vertical 9:16) ou `landscape` (horizontal 16:9).
